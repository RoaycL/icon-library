# Personal Icon Library

个人图标库，供 Surge、Loon、Egern 等工具使用。

## 目录结构

- `data/icons-all.json`：图标目录（1,614 项）
- `icons/`：镜像图标文件；JSON 中的全部图标均托管于本仓库
- `icons/personal/`：个人自用图标（CloudCone、VMISS、DigitalOcean、PaopaoDog、Skylumo、顶级机场）

原始图标资源来自 [fmz200/wool_scripts](https://github.com/fmz200/wool_scripts)，根据其 GPL-3.0 许可证复制并镜像至本仓库；本仓库同样采用 GPL-3.0。

## Claude / Anthropic 图标

- `icons/apps/Claude_01+1.png`：以 [Claude 官方 iOS App Store 图标](https://apps.apple.com/us/app/claude-by-anthropic/id6473753684)为来源，替换旧版带阴影图案，并处理为透明圆角。
- `icons/apps/Claude_02+1.png`：Anthropic 标志，保留原配色与字样，处理为透明圆角。
- 原名称 `Claude_01`、`Claude_02` 及文件保留原版图标。圆角版本以 `Claude_01+1`、`Claude_02+1` 新增到目录，使用不同文件链接；更新订阅后请选择带 `+1` 的新名称。圆角已包含在 PNG 的透明通道中，不依赖客户端裁切。

圆角蒙版使用图像编辑工具生成并清理透明通道，两个图标使用同一蒙版；标志内容来自原始图像，未采用生成工具重绘的内容。Claude / Anthropic 标志归相应权利人所有。
